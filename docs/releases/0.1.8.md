# 国际音标输入法 0.1.8

本版发布 Windows 与 Android。macOS 与 iOS 暂时仍为 0.1.7。

- Windows 改为安装到 `C:\Program Files\PhoneticIPA`，个人键位和配置保存在各 Windows 账户自己的 `%LOCALAPPDATA%\phonetic-ipa-prototype`。从 0.1.7 及更早版本升级时，会复制发起安装账户的键位、规则、配置和用户词库，原解压目录保持不变。解压目录删除后也能卸载。
- 个人键位文件损坏时改用默认键位，并在设置中提示，不再拒绝启动或反复弹窗。规则表载入失败会自动重试。
- 候选没有完整音标时，例如卡拉OK或少见字，显示暂无音标，选择后输入汉字。四端一致。
- 修正含撇号的拼音在部分选词后失效的问题，例如 wo'men'xi'an 选“我”。
- Caps Lock 输出汉字时，Shift＋1–5 仍可输入 ! @ # $ % 和中文标点。直接音标模式还有未确认编码时，Shift＋数字先输入高亮音标，再接调符。
- Windows 工具栏分别显示拼音→IPA、拼音→汉字和 IPA 键盘。
- 切换转写规则更快，内存占用更低。Android 只为当前页候选计算读音，打字和连续删除更顺畅。
- 更新检查每天一次，任一来源可用即视为完成；两个来源都失败时，间隔从 10 分钟逐次加倍，最长一天。Windows 更新提示显示安装包 SHA-256。
- Android 改用不可调试的 release 构建，沿用原签名，可覆盖升级。
- 转写输出字典本调，没有处理连读变调、儿化和轻声音高。

Windows 请解压后运行安装.cmd，升级后重新打开使用输入法的应用，使其加载新版 DLL。旧版程序文件中正被使用的部分会在重启后删除。

验证：Windows 单元测试和真实 Server 管道探针通过；在 Windows 真实 TSF 宿主中完成升级、卸载、重装和自动输入测试。Android release、测试包与 lint 构建通过，签名与 0.1.7 相同；本版未在 Android 模拟器或实体手机上运行。
