# 国际音标输入法 0.1.7

- 修复四个平台 IPA Plus 带圈字母分离、圆圈错位的显示问题，保留原有音标和组合字符。
- Windows IPA Plus 默认适合页面宽度，最高 70%；手动缩放最低降至 20%，增加左右移动按钮。声调与词重调移到右列，减少两列之间的空白。
- Apple、Android 的 IPA Plus 最低缩放统一为 20%。
- Windows 转写规则菜单显示完整名称，例如黄伯荣、廖序东《现代汉语》、胡裕树《现代汉语》。
- 简化 Windows 工具栏，保留输入模式、转写规则和设置，隐藏未接通的按钮及候选后的辅助码提示。
- Windows 新增应用列表卸载入口和卸载.cmd。安装新版会停止本输入法旧进程、解除旧版注册并保留个人键位与配置；安装失败时尝试恢复旧注册。

Windows 请完整解压后运行安装.cmd。升级后保存草稿并重新打开使用输入法的应用，使其加载新版 DLL。卸载保留个人配置和解压目录。

Mac 包含 Intel／Apple 芯片版本，采用本地签名，尚未公证。Android 沿用原签名，可覆盖升级。iOS App 与键盘扩展为 0.1.7 / build 8，仍提供待签名 IPA。

验证：Windows 原生控件 23 项通过；四端带圈字形检查通过；Android／iOS 模拟器键盘流程已验证。Windows 卸载／升级经过隔离脚本测试与安装前检查，当前用户系统的卸载／重装尚未实测。
