# 国际音标输入法 0.1.9

本版发布 Windows 与 Android。macOS 与 iOS 暂时仍为 0.1.7，对应端代码审阅待修清单已归档至 [docs/testing/2026-11-19-apple-待修审阅清单.md](../testing/2026-11-19-apple-待修审阅清单.md)。

- 读音与转写：修复多音字部分选字与跨变体否决缺陷，补齐儿化 `r5`↔`er` 映射，缺轻声词条在基调唯一时自动回退、多基调时保留显式选择。
- 独立产品隔离：隔离本输入法的 TSF GUID、命名管道、设置状态和产品身份，不与原水杉输入法混淆或互相覆盖。
- Windows 界面与皮肤：修复设置页字体与图标 DPI 刷新、DWrite 回退并发锁定与缓存上限；优化候选窗 IPA 排版与命中区、悬浮工具栏宽度/弹窗收敛、设置各分页交互及 `bigfish`、`bigfish-peek`、`ipa-celadon`、`ipa-night`、`ipa-paper` 5 套皮肤细节；修正首次使用教学在四档 DPI 下的滚动视口高度。
- Windows 安装与迁移：新增核心运行库完整性检查和重解析点拒入；升级时将 `msime_user.db` 与 `-wal`/`-shm` 成对原子迁移；安装或注册失败时按步骤回滚。
- Android JNI 与交互：移除已弃用 `codecvt` 并补充互斥锁、空指针和 JNI 异常检查；修复密码框直通、按键按下反馈与多指手势追踪、IPA Plus 中英文/别名/编码搜索与空态提示、设置页生命周期与原地高亮更新，以及更新检查首次失败后的退避间隔与时钟回拨保护。
- 官网下载组件：固定浅色表面对比度，窄屏（≤420px）切单列卡片，完善焦点轮廓、多组件实例与视口边界钳制。

Windows 请完整解压后运行安装.cmd，升级后重新打开使用输入法的应用使其加载新版 DLL。Android 请直接覆盖安装 APK（沿用原签名）。

验证：Windows `0.1.9` 三套 Release 构建、`build-server` 9/9 CTest、`build-x64` 17/17 CTest、`Win32`/`x64` 真实 Server 管道探针及 3 套 PowerShell 安装与偏好测试全部通过。Android `0.1.9` Debug/AndroidTest/Release 构建、`lintDebug`（0 Error）及无窗口模拟器 `core`、`keyboard`、`0.1.8→0.1.9` 原地覆盖升级验证通过（另 `layout` 套件已于升版前在 `emulator-5640` 跑通）。Apple 端本轮未改动，未在 Mac 上编译或运行，真实物理 Android 设备与 Windows 桌面宿主交互暂未在本轮现场重跑。
