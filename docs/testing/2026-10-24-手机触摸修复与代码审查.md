# 0.1.3 手机修复、输入逻辑与代码审查

日期：2026-10-24。验收对象为本次最终 Windows ZIP、macOS ZIP、Android APK 和 iOS 待签名 IPA。未在本次检查前恢复官网输入法入口。

## 修复及原因

| 问题 | 修复与验证 |
|---|---|
| Android 短按直接输入字母、长按音标无法选择 | CIN 单项直接提交，多项或组合打开可点选的固定高度面板。打开、关闭不提交；点击一次仅提交所选 Unicode 一次。触摸测试覆盖 g、v/VoQS、符号及附加符号。 |
| 按键标签消失 | 自绘实际字形时加入 TextView 的 scrollX/scrollY 补偿，避免大字号产生的内部滚动将绘制移出可见区。以全部字母／数字的有效墨迹和实际点击上屏验证。 |
| 键盘过高，功能键换行 | 数字、字母、操作行使用有界 DIP 高度，横屏使用独立紧凑值。操作按钮不随内容拉高。 |
| 手机音标表裁切、过疏 | 默认 50%，按字号计算单元格，上下滑动页面、左右滑动矩阵，提供搜索。IPA/extIPA/VoQS 都有实际滚动和点击验证。 |
| 编辑器附加符号空白 | 完整墨迹预览、显示用虚线圆圈和 Unicode 码位。实际输出保持原始序列，不加入圆圈。 |
| 多音字数字键直接输出汉字 | 默认 IPA 输出路径统一进入读音页，数字选读音后提交。部分拼音组合按引擎返回的原始前缀长度消费，保留后缀。 |
| Shift 切成英文后不能输入音标／声调 | 单按 Shift 切 CIN 并保持 TSF 开启。Caps Lock 独立切 IPA／汉字输出。Shift+1–5 为五度调值，字面 CIN ! 等原映射独立保留。 |
| 只有一套转写 | 复用固定来源的十套列数据，各端可快捷切换。目录／路径／长度／重复 ID 校验，未知或损坏规则不静默替换为另一套。 |
| 设置页过多无关功能、旧产品图标 | Windows 仅显示七项相关设置，替换原创紫色小鸟。保留上游代码和版权说明。 |
| Windows 安装窗口一闪而过 | UTF-8 BOM 的 PowerShell 脚本支持 Windows PowerShell 5.1，CMD 保留结果；失败有非零退出码和日志。完整包与缺失文件负例均验证。 |

## 实际执行的检查

- Windows：Server CTest 9 项、x64 TSF 17 项、x86 TSF 17 项通过。两架构探针连接真实 Server，检查完整词、h→好→hao3/hao4、整词歧义、wu/e 过滤、部分组合和 Shift 声调。隔离测试目录不使用个人学习库。
- Windows 桌面：在本项目创建的普通 Win32 EDIT 中按真实按键。h→1 打开好的读音页，再按 2 得到 xau˥˩。Caps Lock 后 h→1 得到好。恢复 Caps，再单按 Shift、a→1 得到 a；Shift+2、1、4 依次输入 ˨˩˦。反斜杠→1 输入 ˥，斜杠输入 /。打开设置再返回后，首个 a 及数字选候选正常。最终保存文本逐字符断言为 `xau˥˩好a˨˩˦˥/a`，恢复原输入源，关闭专用窗口。
- Android：仅操作本项目无窗口模拟器 emulator-5564。最终 APK 安装后通过 JNI/core 和真实 InputMethodService UI。竖屏 density 480 / font_scale 1.3 与横屏各完整运行一次，涵盖短按、长按、翻页、声调、完整 IPA Plus、编辑器、默认 IPA／汉字和十套规则选择。结束后恢复本模拟器显示参数。实体 Android 设备没有在本次逐一验证。
- macOS：输入源启用与选择成功，先前 -50 问题已有回归。专用 NSTextView / InputContext 经过 IMK 跨进程输入，覆盖默认数字 IPA、Caps Lock 汉字、单按 Shift、Shift 声调、标点、0、歧义词选择。测试恢复输入源及前台应用，全程没有注销。裸 Shift 的 flagsChanged 由测试宿主传给自身 InputContext，未向其他应用注入按键。
- iOS：系统设置启用专用模拟器键盘，在普通 App 文本框实际点按。0.1.3 浅色和深色全流程 UI 测试通过，包括横屏、重开键盘、短按选择、连续 IPA Plus、矩阵横向滚动、附加符号编辑、数字选 IPA／汉字和 Unt 严式实际上屏。模拟器 UDID 为本项目专用实例。未将模拟器通过写成实机签名通过。
- 网站：默认收起，悬停临时显示、点击固定、离开／再次点击／外部点击／Escape 收起。375、390、768、1280、1600 宽度，JS 开／关及触摸均检查。统计新增第三序列，保留旧五／六列历史，新增第七列 IME。9 项采集回归通过。服务器预演保留 3043 条既有历史，回溯到 9 个可证明的 GET 200，19 个无 Range 证据的 206 请求跳过，未改生产统计。

## 审查和再次核对

检查 TSF 分类、延迟回包与 Worker 提交边界，数字／空格与显式鼠标提交共用读音流程。检查取消、返回、分页、未知回包不把原始拼音当作音标提交。检查精确前缀、失败恢复、不将 IPA 学入汉字词库、陈旧候选代次处理。

检查规则的有界读取、文件名校验、原子保存、线程内缓存、手机异步会话代次与 SQLite 固定只读数据。检查导入保留 Unicode、不把预览圆圈写入方案。检查更新解析、来源回退和地址限制；不记录输入文本，不上传个人方案，公开包仅含出厂词库。

iOS 初次快捷规则菜单中末项在下一页，改为键盘内固定高度的可滚动规则面板。一次重开键盘用例假定点入文本框一定将光标放到末尾，断言失败；用例改成验证只新增一个数字且所有原 Unicode 保持不变，重新通过。iOS 设备打包脚本读取 Info.plist 的目录错误已修复，最终设备归档成功。

逐包核对版本 0.1.3、架构、清单哈希、ZIP 完整性和资源来源。补齐十套规则的包内来源；更新 Windows 继承的旧二进制清单。Mac 补来源后重新本地签名并验证，移除签名后的 Mach-O 字节与真实宿主测试版本一致。iOS 仅更新四个来源文本／清单条目，App 和扩展可执行字节不变。Android 补来源后重建 APK 并重跑两种显示条件的完整触摸验证。

Windows 提权确认需要用户操作，自动检查没有代替点击 UAC。macOS 当前为本地签名，未经过 Developer ID 公证。iOS 为 arm64 设备待签名 IPA，须同时签名 App、扩展和正确 App Group；实机的设置共享未验收。手机使用固定词条索引，不声称已经移植水杉整句解码、简拼、模糊音和学习调频。现有各平台用户自行保存的模式偏好继续保留，默认 IPA 适用于新安装／未设置偏好。
