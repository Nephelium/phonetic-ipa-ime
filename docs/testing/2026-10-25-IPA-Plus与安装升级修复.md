# IPA Plus、规则全称与 Windows 安装升级修复

日期：2026-10-25。本地交付，未替换公开下载，未修改当前 Windows 输入法注册。

## 问题与修改

- 带圈字母依赖 PTB IPA Plus 的连字。以 Doulos 为主字体时，基本字母和 U+20DD 会落入不同字体运行，造成截图中的分离。Windows、Apple、Android 的 IPA 字体改以 PTB IPA Plus 为首选。625 个目录条目的输入字符保持原样。
- Windows IPA Plus 默认随控件宽度调整，最高 70%，手动范围 20%–120%。增加左右移动按钮及横向位置提示，保留 Shift＋滚轮。两列按已用高度排布，声调与词重调置于右列。手机及 Apple 的最低缩放统一为 20%。
- Windows 工具栏只保留输入模式、转写规则和设置。繁简转换依赖的资源路径与包内布局不一致，部分上游面板未随产品交付，因此隐藏这些入口及相应设置预览。候选的括号字母为上游辅助码提示，已隐藏，不改变词语或读音数据。
- 展开的规则菜单使用现有完整名称字段，与 PhoneticToolbox、Android、iOS 相同。保留资源中的名称，包括黄伯荣、廖序东《现代汉语》和胡裕树《现代汉语》。紧凑工具栏仍使用短名称。
- 检查时，Windows 正在运行的进程来自 0.1.4 目录，注册路径指向 0.1.6。旧脚本没有关闭旧后台进程，也没有 Windows 应用卸载入口。新安装脚本先验证文件，停止本产品进程，保留个人配置，解除旧注册，再注册新版；失败时尝试恢复旧注册。两种架构逐项检查 COM 与语言配置注册。
- 新增 Windows 应用列表卸载入口及卸载.cmd。卸载解除本产品注册并停止进程，保留个人数据和解压目录。升级无需先手动卸载旧版本，旧文件仍保留。
