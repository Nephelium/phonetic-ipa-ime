# macOS 输入源修复与真实宿主验证

日期：2026-10-23。环境：Apple Silicon Mac，macOS 26.6.2（25G83），Xcode 27.1。未注销、重启或重启系统输入服务。Windows 桌面未操作。远程 Mac 只在获得许可后短暂激活项目专用 NSTextView 测试窗口，每轮结束恢复原应用和输入源。

## 修复内容

原输入源的模式显示已启用，但父输入法未启用。`TISEnableInputSource` 返回 0 后，持久启用列表仍没有本输入法，选择返回 `-50`。本次备份原有列表，保留原有 4 项，只追加本输入法的父项和模式项。通知系统重新读取后，独立进程可见父项和模式均已启用，选择返回 0。

同时发现构建、旧备份和正式安装副本曾使用相同 bundle ID 注册。只取消了本项目非安装副本的 LaunchServices 注册，文件保留。这些重复注册是排查中发现的干扰因素，不能单独解释全部故障。

安装脚本现在：

- 检查来源与目标 bundle ID，先暂存并验证签名。
- 更新需显式 `--update`，旧 Contents 保存在独立时间戳目录，保留目标外层应用目录。
- 只停止目标应用的确切可执行文件，等待它退出再更新。
- 按 Apple SDK 约定先启用父项，再启用模式。
- `--repair-enabled-list` 是显式恢复选项，先保存新备份，再补齐本输入法的缺失项。保留其他项目、顺序与额外字段，拒绝异常数据及检测到的并发修改。
- 注册进程中的状态可能暂时过期，因此另起独立进程核验。以独立核验结果决定安装是否成功。
- 输入法在后台客户端产生组合文本时，不把候选浮窗盖到当前应用上。

重复修复检查显示 6 项保持不变、追加 0 项。没有重置整个 HIToolbox 偏好设置。

## 真实宿主测试方法

`Tests/MacHostTests.m` 是独立 AppKit 应用，只有 NSTextView，没有链接输入法引擎，也不直接调用上屏函数。测试通过带 Quartz backing 的键盘事件进入测试窗口，系统 InputMethodKit 再连接已安装输入法。事件只发给本窗口，不向其他应用或全局桌面注入。

最初使用 `NSEvent keyEventWithType` 构造的事件无法触发组合输入，系统自带拼音对照同样失败。改用 `CGEventCreateKeyboardEvent` 与 `eventWithCGEvent` 后，系统拼音和本输入法都进入 marked-text 流程。失败的测试日志保留，未把它们改成通过。

每个异步步骤都会返回 AppKit 主循环，发送按键前检查本测试窗口是否仍持有焦点。测试成功标记只在文本断言通过、原应用恢复、原输入源重新确认后输出。无前台许可时不传 `--foreground`，后台测试结果不能代替本次前台宿主结果。

## 验证结果

- 更新安装成功，独立核验父项和模式均启用，`TISSelectInputSource=0`。
- `yanwu` 在宿主形成组合文本，按 1 上屏 `厌恶`，组合状态清除。
- 再次输入 `yanwu`，Control＋回车上屏 `jan˥˩ wu˥˩`，没有泄漏换行。
- Shift＋空格切 IPA，`a`、1 上屏 `a`。
- Shift＋2、1、4，再按空格，上屏 `˨˩˦`。
- IPA 模式 `\`、1 上屏 `˥`，`/`、1 上屏 `/`，0、1 上屏 `∅`。无组合时按 6 输入数字。
- `haoxue` 请求 IPA 后等待手动选读音。按 2 选择第二条时仍不提交，再按 Control＋回车得到 `xau˥˩ ɕye˧˥`。
- 最终宿主文本为 `厌恶jan˥˩ wu˥˩a˨˩˦˥/∅6xau˥˩ ɕye˧˥`，原应用、原输入源恢复检查均通过。
- 注册列表合并检查通过，覆盖无关项保留、重复执行不增项、已有元数据保留、缺失父项补齐、异常输入拒绝。
- 共享核心检查覆盖 `wu → 恶` 只保留 wu 读音、整词带调读音、好学歧义、CIN、调值和导入失败后保留原方案。

日志仍可出现 Apple 的 `IMKCFRunLoopWakeUpReliable` 提示，但最终流程成功，不能把该提示本身认定为输入失败。当前证据是专用 NSTextView 的实际跨进程输入。TextEdit、浏览器、Office、第三方编辑器和长时间使用仍未逐一验证。

## 复现

在 Apple 工程目录执行，安装和前台测试均需操作者明确同意：

```sh
bash scripts/install-macos.sh --update --repair-enabled-list
bash scripts/test-macos-host.sh --foreground
```

系统拼音对照：

```sh
IPA_HOST_TEST_SOURCE=com.apple.inputmethod.SCIM.ITABC bash scripts/test-macos-host.sh --foreground
```

合并检查只在内存中运行，不修改系统偏好：

```sh
xcrun clang -fobjc-arc -DIPA_REGISTRATION_TESTS macOS/RegisterInputSource.m -framework AppKit -framework Carbon -o build/registration-tests
build/registration-tests
```
