# 0.1.6 安装器、教学与发布前复核

日期：2026-10-25。范围为 Mac 双击安装器、四端详细首次教学、README／官网新手教程及版本更新。不改变拼音与音标候选算法。保留水杉历史、GPLv3、原始作者与资料来源。

## 修改

- Mac 安装器采用原生 AppKit。随包预编译 Intel／Apple 芯片安装器、注册助手与输入法应用。安装阶段只调用 macOS 系统工具，不运行 xcrun、clang、swiftc 或 xcode-select。
- 目标为当前用户的独立 Input Methods 应用。升级保留外层应用目录，以 renamex_np / RENAME_SWAP 原子交换 Contents，避免短暂缺失 Info.plist。旧 Contents 与记录保留在用户 Application Support 中。
- 已有启用记录的刷新只涉及本输入法，先备份并进行并发读回检查，保留其他输入源的顺序与元数据。注册后由另一个 GUI 进程复核。安装不注销、不重启系统输入服务。
- 安装器默认展示可读的结果，技术诊断由查看详细记录按钮展开。已有输入法进程通过固定通知打开设置，首次启动通过 --settings 参数打开。
- 四端教学扩充四页，区分输入方式与拼音默认输出，给出实际状态名称、Shift／Caps Lock、数字选字后再选读音、直接音标、214 声调、IPA Plus 与规则切换。使用 v2 完成标记，让已有用户升级后阅读一次。
- Windows 教学保持大肥鱼示意，Mac／手机使用原生样式。长内容滚动，导航按钮保留。README、安装指南与官网教程采用一致的状态与例子。

## 发现并处理的问题

Mac 的第一轮成功不足以覆盖重复升级。追加测试暴露了注册进程返回成功而独立目录不可用的情况，早期测试断言曾产生系统问题报告，失败日志保留。后续保留完整应用元数据、刷新本输入法的启用记录，并以独立目录和实际打字共同判定，最终重复验证通过。

早期 AppKit 内容视图抓图遗漏窗口背景，透明区域显示为黑色。最终图像由原生控件绘制并合成窗口背景，示意图与实际安装操作分别记录。该图像绘制通过不单独代表安装或真实宿主打字通过。

## 验证范围

Mac 实测为租用的 Apple Silicon、macOS 26.6.2、Xcode 27.1 账户。安装目录为空的测试账户以前注册过本输入法，因此不称为全新 macOS 用户首次安装。没有卸载 Xcode，运行阶段无开发工具调用的证据来自代码、系统 PATH、无效开发目录、依赖检查与实际安装。Intel／macOS 13 做了二进制与最低版本检查，未进行物理机器实测。

本轮 Windows 输入算法未改，新增教学与最终包做了上述检查，未重新对所有第三方编辑器逐个打字。Android／iOS 为项目专用模拟器，未代替各厂商实体手机、iPhone 自行签名与 App Group 实机验证。Mac 仍为本地签名、尚未公证，iOS 仍为待签名包。

公开上传、服务器文件哈希、下载 HTTP 范围请求、线上页面和两个版本源的结果另存部署回执。完成这些步骤前不将本地测试视为已公开发布。

## 发布前文字调整

按用户要求保持当前 0.1.6 / 7 不变，所有用户可见的 CIN 模式名称统一为 IPA，导入导出按钮统一称 IPA 码表，实际 .cin 格式与内部接口保留。开头说明改为默认拼音输出音标、Caps Lock 切为拼音输出汉字、单按 Shift 切为字母或符号选择音标。手机 IPA Plus 可直接输入，桌面设置中用于编辑键位。

此轮文字修改仅重新编译、打包和上传，按用户要求未重复运行前述功能、界面、宿主和模拟器测试。前述记录描述文字调整前已执行的检查，未将未执行的检查计为再次通过。
