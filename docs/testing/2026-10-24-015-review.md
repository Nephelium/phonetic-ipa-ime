# 0.1.5 代码复核与验证

日期：2026-10-24。本轮在 0.1.4 输入逻辑基础上修复 Windows 教学入口和皮肤打包遗漏，更新四端图标。前轮输入逻辑的详细记录见 [0.1.4 验证](2026-10-24-014-review.md) 和 [手机触摸修复与代码审查](2026-10-24-手机触摸修复与代码审查.md)。

## 修复与复核

- **Windows 皮肤遗漏**：开发目录有大肥鱼，旧 ZIP 只复制了少数主题。新打包入口复制普通、探头、国庆献礼三套原始 TOML 和素材，并从最终 ZIP 解析皮肤路径、逐一校验。新安装配置的默认值明确为普通 `bigfish`。原作者、来源和图片元数据保留。未将开发者正在使用的配置作为出厂配置。
- **已有安装不再出现教学**：用户目录已有 `onboarding-v1.done`。安装后显式发送 `--guide`，设置进程已运行时转发教学请求。新增使用教学启动器，已经完成教学的用户也能重看。普通安装由未提权的父进程打开窗口；直接以管理员运行安装器时，也在注册成功后打开。缺少安装内容会留下非零退出码和日志。
- **四端默认图标**：统一使用参考水杉普通大肥鱼角色制作的抱 ə 图标。Windows EXE/DLL 资源、设置页图标、Android mipmap、自适应图标和 Apple 图标目录分别替换。制作参考和原图哈希见 [图标说明](../../assets/icons/README.md)。
- **Windows 自选图片显示图标**：只在 Windows 关于页提供。WIC 解码实际 PNG/JPEG/BMP，限制 10 MB、单边 8192 和 3200 万像素，居中裁为方形并缩放为 256 像素 ICO。成功解码后才原子更新私有目录中的图标指针。文件名有界读取且不能含目录分隔符，无效图片不改变已选图标。恢复默认清空指针，保留原图和转换文件。用于设置窗口、任务栏和应用内标志，不修改 EXE/DLL 文件图标。macOS 和手机没有任意图片图标入口。
- **来源署名**：README 开头、关于页、图标记录、第三方资料和修改记录显式链接水杉原项目。保留上游 Git 历史、原始许可证和版权，不将上游角色称为本项目原创。
- **发布内容**：按最终 ZIP 全成员 SHA-256 清单检查，拒绝教学完成标记和个人 custom-icon 文件。出厂词库固定 SHA-256 为 `9e68e88be036206fc14d44db7111376b1d92f9173b04d623e601e31edd664c2f`，未使用个人学习库。
