# 0.1.6 手机候选与图文教程补丁

版本继续为 0.1.6，iOS build 7。

## 改动

- iOS 候选栏根据内容测量高度，键盘总高度随候选内容调整。普通候选、二次读音选择和声调候选均保留完整行高。
- iOS 26 及以上关闭候选横向滚动区域的系统边缘遮罩。手机候选汉字 17 点，IPA 18 点，读音提示 10 点，减少上下行间距。
- Windows、macOS、Android 和 iOS 的设置显示 PhoneticToolbox 官网链接。
- 网页教程按四个平台、八个章节、21 个步骤组织，每步提供截图、操作标记、按键顺序和结果说明。

## 实际执行

- iOS 模拟器完整键盘与设置 UI 检查通过，2 个测试，0 个失败。包括汉字、IPA、读音选择、声调、符号面板、IPA Plus 的 IPA/extIPA/VoQS、横向音标表与候选编辑预览。
- 普通词候选、读音候选、声调候选和八字词候选在横竖屏均检查候选控件底部位于数字行上方。另实际按键输入中华人民共和国、全国人民代表大会与一串较长拼音，保存截图。
- Android JNI/core、实际键盘和设置 UI 检查通过。长按退格、松手停止、移出按键取消和选择文本后删除均保留精确 Unicode 结果检查。短按测试改为明确短于长按阈值的按下/抬起，避免测试手势被误认为长按。
- Android 普通候选、读音选择和声调候选横竖屏位置检查通过。Gradle assembleDebug、assembleDebugAndroidTest、lintDebug 通过，APK 沿用原测试签名。
- Windows 设置目标编译通过。Mac app 与双击安装器构建通过。此补丁未修改两端输入算法或安装逻辑，沿用上一轮相关行为证据。
- iOS 最终待签名包的 arm64 / iOS 平台检查通过。本地恢复的 IPA 与构建机输出 SHA-256 完全相同。Mac 安装器文件逐项比对构建机清单，Windows 包内部 SHA-256 清单一致。
- 网页四个平台全部 21 步在 320、390、768、1440 像素宽度下完成检查，图像加载、操作标记、放大和页面横向边界正常。

## 证据范围

手机检查使用项目专用 Android 模拟器和 iOS 模拟器，尚未在实体 iPhone 上执行此轮检查。网页的手机截图来自系统键盘实际操作，Windows/macOS 示意图由产品原生候选和设置控件渲染，并在教程中标明。

手机目前按固定词库查完整词语。未收录的任意整句拼音可能没有候选，长句需分词确认。此限制已在网页教程写明。
