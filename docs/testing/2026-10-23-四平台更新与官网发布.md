# 四平台更新与官网发布

## 变更

0.1.1 / build 2 接入官网和 GitHub 双来源版本检查。自动检查以 24 小时为正常间隔，失败来源最早 10 分钟后可重试；实际检查还取决于 App 前台、输入会话启动或桌面后台定时器。Windows 使用独立 HKCU 偏好，Apple 使用 UserDefaults，Android 使用独立 SharedPreferences。

元数据限制为 64 KiB，校验产品、schema、三段数字版本、平台下载项、长度与 SHA-256 格式，下载地址限定本项目的 HTTPS 官网目录和 GitHub Release。仅提醒和提供浏览器下载，不进行静默安装。

官网在已有工具箱下载组下增加原生 details/summary 四平台展开区，沿用奶油色、紫色描边和浅色卡片。独立 CSS 与生成器中的组件同步。发布基于线上首页，仅添加此区域和它的 CSS 引用，不带入本地其他未发布页面改动。

- Android Debug / AndroidTest 构建与 lint 通过。专属无窗口模拟器 emulator-5564 中 JNI 与真实 InputMethodService 回归通过，最终文本 `厌恶wu˥˩a˨˩˦6˥/`。证据 `output/android-qa/verified-20261023-203402/`。

## 2026-10-24 公开验证及后续修订

0.1.1 已发布至官网与 GitHub Release。四个官网下载包完整 HTTP 读回与本地 SHA-256 相同，GitHub 资产 API 的 digest 与本地一致，公开下载链接返回 200。两个线上清单内容相同。Windows WinHTTP 和 Apple URLSession 的实际客户端检查均同时读取两个线上清单并确认当前版本。

Android 专用模拟器直接连接官网成功，连接 raw.githubusercontent.com 超时，实际客户端正确显示一个来源可用。仅给 instrumentation 进程配置 QA 代理后，两个来源实际检查通过。未修改用户设备或系统网络配置，生产 APK 保持原字节。该网络差异保留在验证记录中。

井井反馈 Windows 安装窗口闪退。后台用系统 PowerShell 5.1 / ANSI 936 复现脚本解析错误：初版 UTF-8 无 BOM 被当作系统编码读取。r2 为安装与启动脚本补充 BOM，批处理窗口保留结果，预检缺少文件时明确退出 1 并写日志，提升权限后的退出码传回入口。Windows 5.1 正向预检、中文含空格路径与缺失包的错误日志检查通过。本轮未在桌面触发 UAC 或重新注册，由井井实测安装。r2 只修改打包脚本和说明，应用 EXE/DLL 与词库保持原字节。

官网下载区按最新反馈改为浮窗，默认隐藏。鼠标悬停预览，移开收起，点击固定，再点按钮、空白处或 Esc 关闭；手机点击切换。面板不增加 hero 布局高度，按视口空间向上或向下显示。预览含五宽度、开关 JS 共十组及触屏一组检查通过，无 JS 仍可点击展开。
