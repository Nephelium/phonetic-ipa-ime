# 四平台更新与官网发布

## 变更

0.1.1 / build 2 接入官网和 GitHub 双来源版本检查。自动检查以 24 小时为正常间隔，失败来源最早 10 分钟后可重试；实际检查还取决于 App 前台、输入会话启动或桌面后台定时器。Windows 使用独立 HKCU 偏好，Apple 使用 UserDefaults，Android 使用独立 SharedPreferences。

元数据限制为 64 KiB，校验产品、schema、三段数字版本、平台下载项、长度与 SHA-256 格式，下载地址限定本项目的 HTTPS 官网目录和 GitHub Release。仅提醒和提供浏览器下载，不进行静默安装。

官网在已有工具箱下载组下增加原生 details/summary 四平台展开区，沿用奶油色、紫色描边和浅色卡片。独立 CSS 与生成器中的组件同步。发布基于线上首页，仅添加此区域和它的 CSS 引用，不带入本地其他未发布页面改动。
