# 2026-11-19 Apple 端待修审阅清单（静态核查归档）

本清单基于 2026-11-19 代码审阅及源码级交叉复核结果整理，记录 `apple/` 下 macOS InputMethodKit 与 iOS 键盘扩展/配套 App 存在的待修复缺陷与视觉体验改进项。因当前无 Mac 构建环境，本轮未改动 `apple/` 源码，留待后续在 macOS 环境统一实施并完成编译、单测与真实宿主验证。

> 注意：以下编译结论基于静态逐行核查；运行时表现与 Xcode 实际编译需在 Mac 上复验。

## 一、P0 高危问题（崩溃 / 内存红线 / 宿主数据破坏）

1. **`macOS/main.swift` 缺失 `withExtendedLifetime(delegate)`，Release `-O` 下 `IMKServer` 可被提前释放**
   - **位置**：`apple/macOS/main.swift:200-206`（对比 `apple/macOS/Installer.swift:219`）
   - **问题**：`NSApplication.delegate` 为弱引用，`main.swift` 在闭包内创建局部 `delegate` 后直接调用 `app.run()`。Release 优化下 ARC 可在事件循环前销毁 `delegate` 及其持有的 `IMKServer` 与 `settingsObserver`，导致输入法静默失效。
   - **建议方案**：改用 `withExtendedLifetime(delegate) { app.run() }`，或将 `delegate` 提升为静态/顶层强引用。

2. **macOS `flagsChanged` 无条件调用 `setMarkedText("")`，会删除宿主已选中文本**
   - **位置**：`apple/macOS/main.swift:111, 169-171`
   - **问题**：每次按下或松开修饰键（`Cmd`、`Shift`、`Option`、`Control`）都会触发 `updatePresentation()`。当 `model.raw.isEmpty` 时，`L170` 调用 `setMarkedText("", selectionRange: {0,0}, replacementRange: {NSNotFound, 0})`。按 `NSTextInputClient` 契约，这会用空串替换当前选区，用户在编辑器选中文本后刚按 `Cmd`（准备 `Cmd+C`）或 `Shift` 即删掉选区内容。
   - **建议方案**：在 `PhoneticInputController` 维护 `hasMarkedText` 状态，仅在确实存在组合态且需清空时调用 `setMarkedText("")`；`insertText` 提交前先置 `hasMarkedText = false`。

3. **iOS 键盘扩展 `PlusPicker` 每次重绘同步解析 908 KB JSON，易触碰约 48 MB Jetsam 红线**
   - **位置**：`apple/Shared/KeyboardViews.swift:331-336, 346`；`apple/iOS/KeyboardViewController.swift:136-138`
   - **问题**：`PlusPicker` 为值类型结构体，`private let catalog = PlusCatalog.load()` 在每次 `TouchKeyboard.body` 重算时都在主线程重新读取并反序列化 908 KB `plus-catalog.json`，在 IPA Plus 中每点一次符号就会带来 8–15 MB 瞬时内存峰值，极易被系统强杀退回系统键盘。
   - **建议方案**：将 `PlusCatalog` 改为惰性缓存单例并附带 `[String: PlusEntry]` 字典索引（顺带消除 `L443`、`L473` 线性查找），并在 `KeyboardViewController.didReceiveMemoryWarning()` 清理缓存及调用 `sqlite3_db_release_memory`。

4. **`reloadProfile()` 每次切换应用/唤起键盘重建第二个 `IPAEngine`，且 `macOS/Info.plist` 双倍实例化控制器**
   - **位置**：`apple/Shared/InputModel.swift:285-290, 297-313, 325-333, 336-354`；`apple/macOS/main.swift:11, 64, 77`；`apple/macOS/Info.plist:31-34`
   - **问题**：
     - 存在 `profile.json` 时，每次 `activateServer`/`viewWillAppear` 都会新建整套 `IPAEngine`（先解析 `beijing.tsv` 再重开 1 MB SQLite）与旧实例并存；且 `L311` 对 `pageSize` 赋值早于 `defer { reloadRule() }` 触发 `didSet`，随后 `reloadRule()` 又重解析最高 540 KB 规则表。`importProfile` 时甚至同时存在 3 个实例。
     - `apple/macOS/Info.plist:31-34` 同时把 `InputMethodServerControllerClass` 和 `InputMethodServerDelegateClass` 设为 `PhoneticInputController`，每个宿主进程都会生成双倍控制器与引擎。
   - **建议方案**：复用现有 `IPAEngine` 加载 CIN（其本身具原子回滚）；缓存 `profile.json` 与 `rule-selection.txt` 修改时间按 `mtime` 短路；删除 `Info.plist` 多余的 `InputMethodServerDelegateClass`，并在 macOS 进程内单例共享引擎；临时 `.cin` 移至 `temporaryDirectory`。

## 二、P1 重要缺陷（编译隐患 / 功能失效 / 交互断层 / 强解包崩溃）

5. **构建工程与版本脚本过时，及 Xcode 16 SDK 编译风险**
   - **位置**：`apple/PhoneticIPA.xcodeproj/project.pbxproj:30-31, 48-49, 61-62, 72-73`；`apple/scripts/build.sh:13-14`；`apple/scripts/build-macos-installer.sh:34`；`apple/Shared/KeyboardViews.swift:154`
   - **问题**：仓库提交的 `project.pbxproj` 仍停留在 `0.1.1` / build `2` 且缺 `.lproj` 引用，`build.sh` 未自动运行 `python3 scripts/project.py`，`build-macos-installer.sh:34` 硬编码 `CFBundleVersion` 为 `8`。`KeyboardViews.swift:154` 使用 iOS 26 API `.scrollEdgeEffectHidden()` 而无 `#if compiler(>=6.2)` 条件编译保护，在 Xcode 16（iOS 18 SDK）下会直接编译失败。
   - **建议方案**：在 `build.sh` 与 `package-unsigned.sh` 开头运行 `python3 scripts/project.py`（或提交同步后的工程文件）；`build-macos-installer.sh` 动态读取版本号；用 `#if compiler(>=6.2)` 包裹 `.scrollEdgeEffectHidden()`。

6. **0.1.8 H5 未打通 UI：点击“暂无音标”按钮仍被禁用**
   - **位置**：`apple/Shared/KeyboardViews.swift:227-234`（对比 `apple/Shared/InputModel.swift:234`）
   - **问题**：`InputModel.choose(_:ipa:)` 已支持无音标时提交汉字，但 `KeyboardViews.swift:232` 仍保留 `.disabled(candidate.ipa.isEmpty && candidate.reading?.ambiguous != true)`，导致点击该行完全无效。
   - **建议方案**：移除 `.disabled(...)`，将无音标提示改用小号系统字体并显示“暂无音标 · 输入汉字”。

7. **`IPAEngine.mm` 未判空 `sqlite3_column_text`、缺 C++ 异常保护，且丢弃显式撇号 `'`**
   - **位置**：`apple/Shared/IPAEngine.mm:55-113, 132-137`
   - **问题**：
     - `L61`、`L97-98` 未判空 `sqlite3_column_text`，极端 OOM（`SQLITE_NOMEM`）时传入 `istringstream` 或 `@(...)` 会触发 UB / `NSInvalidArgumentException` 崩溃；4 个桥接方法缺少 `try/catch (const std::exception &)`，C++ 异常跨 ObjC++ 边界会 `std::terminate()`；`_readings` 复用语句无互斥保护。
     - `L91` 删除输入中的撇号 `'` 后仅按 `WHERE code=?` 查询，导致输入 `xi'an` 时被高频单字（先、现等）淹没，找不到 `canonical="xi'an"` 的“西安”。
   - **建议方案**：所有 `sqlite3_column_text` 显式判空；补齐 `try/catch` 并在异常路径调用 `sqlite3_reset`；加锁或标注 actor 隔离并顺带缓存 `candidates:` 预处理语句；当原始输入包含 `'` 时同时匹配 `canonical=?`。

8. **macOS 候选窗系统级定位缺陷（全屏 / 多屏 / Spotlight / 边界）**
   - **位置**：`apple/macOS/main.swift:168-197`
   - **问题**：`NSPanel` 缺 `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary, .ignoresCycle]`（全屏 App 不可见或触发切屏）；`0` 宽 `caret` 使 `intersects` 恒为 `false` 致副屏打字飘到主屏；`isActive` 强校验在 Spotlight/Raycast 隐藏面板；`L194` `else` 分支缺下界 clamp；`raw.isEmpty` 隐藏面板与教学“空闲状态提示”矛盾。
   - **建议方案**：补全 `collectionBehavior`；用 `NSPointInRect` 或至少 clamp `1×1` 矩形匹配屏幕（`caret == .zero` 时退回鼠标所在屏）；双分支统一 clamp 到工作区边界；豁免非激活浮层或补充切态轻提示 HUD。

9. **macOS 键盘交互断层：`tone:214` 无法用数字选词、缺左右键、Shift 误切与标点毁组合**
   - **位置**：`apple/macOS/main.swift:87-91, 121-125, 137-138, 153-157`；`apple/Shared/InputModel.swift:215`
   - **问题**：
     - `L153` 排除 `!model.raw.hasPrefix("tone:")`，导致 `tone:214` 候选弹出时按数字 `1/2/3` 无法选 `˨˩˦`/`²¹⁴`/`214`，反而拼成 `tone:2142`。
     - 横向 `CandidateStrip` 只响应上下键（`125`/`126`），忽略左右键（`123`/`124`）。
     - 拼音态按 `,`/`.`/`0` 拼入 `raw` 直接清空候选；CapsLock 汉字模式下 `candidates.isEmpty` 时 `Shift+1..5` 会留残余组合串。
     - `toggleMode()` 直接 `clear()` 丢弃已输入拼音；`mouseDownCount()` 漏统计 `.scrollWheel`，`Shift + 滚轮` 易误切模式。
   - **建议方案**：`tone:` 模式下数字 `1–3` 选候选并拦截非法字符；补 `123`/`124` 左右移动高亮；拼音态遇非拼音标点先上屏首项再透传；无候选时补清 `raw`；`mouseDownCount()` 补 `.scrollWheel`，计时改用 `systemUptime` 并在 `deactivateServer` 复位 `shiftArmed`。

10. **`SettingsView` 删除候选越界崩溃与切 Tab 覆盖编辑；`default.cin` 重复项致 SwiftUI ID 冲突**
    - **位置**：`apple/Shared/KeyboardViews.swift:218, 546-554, 583`；`apple/Shared/InputModel.swift:28`；`apple/Generated/IPA/default.cin:172-180, 251-256, 510-513`
    - **问题**：`ForEach(outputs.indices, id: \.self)` 绑定 `$outputs[index]` 在删除末项时易触发 `Index out of range` 崩溃；`.onAppear { chooseCode(code) }` 在切 Tab 后覆盖未保存编辑。`Candidate.id` 为 `word + "\t" + canonical`，但 `default.cin` 含 `r ʁ`、`l ̩` 等重复映射，致输入 `r` 时 SwiftUI `ForEach` ID 冲突。
    - **建议方案**：改为带 `UUID` 的 `Identifiable` 编辑模型与 `ForEach($outputs)`；用 `initialized` 标记防重入覆写；`Candidate` 增加唯一 `index: Int`（或 `UUID`）。

11. **iOS 键盘未处理“未开启完全访问”、无长按连删、安全区侵入灵动岛及符号页缺陷**
    - **位置**：`apple/Shared/InputModel.swift:96-104, 355-365`；`apple/iOS/KeyboardViewController.swift:60, 168-172, 177, 205-228`；`apple/Shared/KeyboardViews.swift:54`
    - **问题**：
      - 未开“允许完全访问”时写 App Group 失败直接回滚规则切换并报英文 Cocoa 错误。
      - 退格键无长按连删（违背教学）；`.ignoresSafeArea(.container)` 加在最外层致横屏按键侵入刘海/灵动岛；iPad 横屏误用紧凑布局按键被压到 28pt；上划手势绑在全部 `0–9` 吞掉 `6–9/0` 轻滑；地球键缺长按列表 `handleInputModeList`；符号页残留无效 `⇧` 键且缺反引号 `` ` ``（致使 6 个附加符号不可达）。
    - **建议方案**：检测 `hasFullAccess` 提供本地容器回退与友好提示；退格补长按定时连删；仅对背景应用 `.ignoresSafeArea()`；用 `verticalSizeClass == .compact` 判紧凑布局；仅对 `1–5` 绑上划；地球键改原生 `UIButton` 绑定 `handleInputModeList`；符号页去 `⇧` 补 `` ` ``。

12. **`Updates.swift` 强解包崩溃与退避逻辑跳档**
    - **位置**：`apple/Shared/Updates.swift:23-29, 66, 89, 99, 119-122, 134, 139-140, 171-172`；`apple/macOS/main.swift:21, 37-38`；`apple/iOS/PhoneticIPAApp.swift:28-29`
    - **问题**：存在多处 `URL(string:)!` 与 `ReleaseVersion()!` 强解包；0.1.8 首次失败先写 `failures = 1` 再算 `600 * 2^1 = 1200s`（跳过 10 分钟首档），且 macOS `updateTimer` 写死 1 小时吞掉前 3 档退避。
    - **建议方案**：`trusted(_:)` 增加 `URL(string:) != nil` 与 ASCII 路径校验，消除所有 `!`；退避改为按 `failures - 1` 翻倍；更新页补充展示 `download.sha256`。

## 三、P2 问题（性能、合规与健壮性）

13. **`RegisterInputSource.m` 并发更新列表失败后未恢复本输入法**：`apple/macOS/RegisterInputSource.m:64-80` 探测期间若启用列表被其他进程修改，`L78` 直接 `return NO` 而未合并恢复本输入法条目。
14. **渲染与状态广播性能隐患**：
    - `InputModel.resolveVisible()`（`InputModel.swift:166-177`）单页修改 `@Published var candidates` 多达 18–27 次，且切换 `pageSize` 未 clamp `page`。
    - `KeyboardViews.swift:5-13` `Font.ipa` 每次 `body` 重算都新建 `CTFont`；`KeyboardViewController.swift:199, 203` 直接模式对 26 键每帧 52 次全表线性扫描，应预计算前缀集合降为 O(1)；`L48` 每次击键无条件写 `UserDefaults`。
15. **iOS 上架合规与包体积问题**：
    - `KeyboardViews.swift:52` iOS 教学第 1 页混入 Android 操作说明（App Store 审核风险）。
    - `App-Info.plist:32-37` 缺 `UISupportedInterfaceOrientations~ipad`；`PhoneticIPAApp.swift:8` 对单例错用 `@StateObject`。
    - `apple/scripts/project.py:57-58, 67-69` 将 101.5 MB `lookup.sqlite` 同时打进主 App 与键盘扩展（包体翻倍），主 App 不查拼音应按需延迟加载。
16. **长按菜单与规则菜单体验瑕疵**：`KeyboardViews.swift:182-189, 238` iOS 键盘扩展内系统 `.contextMenu` 易裁切卡顿；macOS `Menu("规则")` 易抢 `.nonactivatingPanel` 焦点，建议改非激活 `NSMenu.popUpContextMenu`。

## 四、UI 美化与跨端体验改进项

17. **macOS 候选窗与安装器视觉精修**：
    - `apple/macOS/main.swift:28-45, 181-195`：将固定 `680×145pt` 直角不透明实色框改为 `.clear` + `.regularMaterial` 毛玻璃 + `14pt` 连续圆角与柔和阴影，宽度随内容在 `[240, 680]` 动态收缩。
    - `apple/macOS/Installer.swift:54-191`：安装完成后默认收起日志框（消除与上方静态正文 100% 复读的问题），将「打开输入法设置」设为主强调按钮与 `keyEquivalent = "\r"`。
    - `apple/macOS/Info.plist:23-24`：考虑用 `LSUIElement=true` 替代 `LSBackgroundOnly=true` 以协调设置窗口交互。
18. **iOS 暗黑模式对比度与原生质感修复**：
    - 修复暗黑模式回车键白图标压亮薄荷绿 `#8AD6D1`（对比度约 1.75:1）与教学按钮暗靛蓝压深黑（约 2.8:1）的问题；统一同屏薄荷绿、系统蓝与靛蓝三色冲突。
    - 键盘底色改 `.clear` 透出 `UIInputView(.keyboard)` 系统毛玻璃；固定候选栏舒适高度防止打字时整块键盘上下跳动 64pt；拼音模式键帽用系统无衬线体（IPA 模式保留 `Doulos SIL`）；“选择读音…”改用 `.caption` 系统字体；`TextEditor` 补 `.scrollContentBackground(.hidden)`；补充 `UIImpactFeedbackGenerator` 轻触反馈与按键放大/声调预览气泡，并优化 `TouchSymbolPicker` 易混音标微标签与长单键胶囊隐藏。
