# 0.1.4 代码复核与验证

日期：2026-10-24。官网输入法下载维持撤下。本文区分源码、控件渲染、真实宿主、模拟器和安装包检查。

## 已修正

| 问题 | 修正与核查 |
|---|---|
| 已升级文件，运行中的应用仍表现为旧版 | 对 ChatGPT 进程只读检查本产品 DLL 的 PE 头，确认其加载时间戳与旧 DLL 一致。更新说明提示保存草稿并完全退出后重开应用，不自动关闭用户应用。微信重启后正常由用户确认。 |
| Windows 规则列表向下展开 | 菜单内容排在工具栏上方，调整窗口顶边时保留工具栏行的位置。屏幕边缘沿用工作区约束，长规则名称不再按半屏宽度裁切。 |
| 规则显示名称 | 使用 Standard Chinese Beijing 宽／严、UntPhesoca 宽／严。规则 ID、逐字转写表和原始来源列名保持不变，导出前后逐文件 SHA-256 一致。 |
| 设置仍显示双拼示例 | 候选预览改用 ni 和实际规则换算的 IPA，词条多音时显示选择读音。工具栏预览显示 IPA、规则名称和实际功能项。关于页使用当前应用图标，移除 Server 对小图标的系统默认覆盖。 |
| Android 退格只能逐次点按 | 独立重复按键，长按启动，松手、移出按键、触点取消、隐藏或重建键盘、切换输入宿主与销毁时取消定时器。 |
| Android 选区删除影响前一个附加符号 | 删除选区前结束残留 composing span，再提交空文本。模拟器验证选区删除后保留前一个组合附加符号。 |
| Android 字号与模式名称 | 汉字候选由 21 DIP 改为 17 DIP，IPA 字号保留。左下角音标模式显示 IPA。按照用户澄清，候选查询、短按与选读音逻辑保持原样，撤回拟加的拼音前缀补全。 |
| 首次打开不知道如何使用 | 四平台增加离线四步教学和重新打开入口。Windows 使用原有大肥鱼素材，Mac／手机使用原生界面。Windows 教学按钮弱引用避免回调持有控件的循环引用，Android Activity 销毁时关闭教学对话框。 |
| Mac 更新时输入源注册不稳定 | 清理本项目已知构建目录中同 bundle ID 的注册，保留文件与旧安装备份。新版本 0.1.4 / build 5 注册后独立核验通过。随后同版本重复安装也通过核验。 |
| Mac 前台测试偶发失焦 | 日志确认部分失败轮次的焦点被系统设置取得。移除不必要的应用 reopen 处理后仍出现过一次，尚不能把原因完全归于该处理。用户确认未操作 Mac 后，最终版本专用宿主重新完成全流程，并核验原应用与输入源恢复。失焦即停止输入的检查保留，未注销或重启系统服务。 |
| Apple 资源清单与索引不一致 | 最终包逐文件校验拦下 lookup.sqlite 的旧哈希。确认固定索引 SHA-256 与 1,268,935 个候选、183,177 个读音记录不变后，只修正清单。构建与待签名打包入口新增严格验证，旧清单负向测试失败、新清单正向测试通过。 |
