## 给接手者的提示

- **构建走 ASCII junction**：`%USERPROFILE%\ipa-prototype-workspace` 指向本项目。vcpkg 在中文路径下会失败。
- **离线重配置**：`scripts/build-prototype.ps1` 重新配置时 vcpkg 会下载 PowerShell 7，没有代理就失败。依赖已装在各 build 目录里，本轮用同样参数加 `-DVCPKG_MANIFEST_INSTALL=OFF` 重配置后，server、x64、x86 都构建成功。
- **Server 产物不在 bin\Release**：`output/build-server/CMakeCache.txt` 里的 `CMAKE_RUNTIME_OUTPUT_DIRECTORY_RELEASE` 指向 `output/fixes-20261024/windows-next`，新编的 exe 和测试都在那里，`build-server/bin/Release` 还是 10-24 的旧文件。`scripts/stage-prototype.py` 已改为读取这个缓存值。打包前请核对 exe 时间戳。
- **环境变量已改名**（报告 L3）：`METASEQUOIA_IME_DATA_DIR` 和 `METASEQUOIA_IME_CONFIG_DIR` 改为 `PHONETIC_IPA_DATA_DIR` 和 `PHONETIC_IPA_CONFIG_DIR`。上游 CI 脚本 `msime-windows/scripts/ci/*.ps1` 按项目约定未改，仍用旧名。
- **编辑注意**：
  - 文件换行符不统一，CRLF 与 LF 都有；安装脚本带 UTF-8 BOM（PowerShell 5.1 需要）。
  - Git Bash 的 `sed -i` 会把 CRLF 改成 LF，heredoc 也会吞反斜杠。补丁脚本应写成文件，再用 Python 按字节替换，并保留 BOM 和换行符。
- **格式检查**：改完 C++ 用 `tools/clang-format-py/clang_format/data/bin/clang-format.exe`（18.1.8）运行 `--dry-run --Werror --style=file`。本轮改动的文件都已通过。

实测中发现并修正了三处问题：
- 上游 DLL 反注册后留下空的 TIP 键，现在卸载时一并删除。
- PowerShell 把 `$null` 作为空字符串传给 MoveFileEx，导致被占用的文件没有安排重启删除。现改用 `[NullString]::Value`，并改为最后删除标记文件；按安装器命名格式 `app-版本-14位时间` 的残留文件夹也会被清理。
- 引擎运行时会写入 `msime.db` 等数据库，原先的出厂刷新会覆盖它们（旧安装器同样如此）。现在这些库只在 `dictionary-manifest.json` 变化时更新，并保留 `.before-upgrade-<stamp>` 副本；大小和时间相同的文件直接跳过。
