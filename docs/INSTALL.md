# 国际音标输入法 0.1.1

从 [官网](https://www.phonetictoolbox.com/#ipa-ime-download) 或 [GitHub Releases](https://github.com/Nephelium/phonetic-ipa-ime/releases/tag/v0.1.1) 下载对应平台的测试包。

## Windows 10 / 11 x64

解压 ZIP 到准备长期保留的可写目录，双击 `安装.cmd` 并确认管理员授权。按 Win＋空格选择国际音标输入法原型。双击 `打开设置.cmd` 编辑键位，在关于页检查更新。

升级前退出此输入法及设置，备份旧目录 `output/runtime/data` 中的自定义配置和码表。新包解压到新目录后重新安装。程序未作发行签名，管理员权限应用的输入与候选窗尚未验收。

## macOS 13 及以上

支持 Intel 和 Apple 芯片。解压 ZIP 后，在终端进入该目录，运行 `bash 安装.command`。已有本输入法时运行 `bash 安装.command --update`。

当前安装脚本需要 Xcode 命令行工具。程序安装到当前用户的 `~/Library/Input Methods/PhoneticIPA.app`，旧版本和配置修复前备份保存在解压目录 `build/install-backups/`。然后从系统输入法菜单选择国际音标输入法。程序使用临时本地签名，未经过 Apple Developer ID 公证。系统拦截时按隐私与安全性界面核对来源，不关闭系统安全保护。

## iPhone / iPad · iOS 16 及以上

这是 **待签名 IPA**，下载后不能直接点击安装。需要为主 App 和嵌入的键盘扩展签名，并为两者配置相同的 App Group。具体步骤见 [待签名包说明](../apple/INSTALL-unsigned.md)。

安装后打开系统设置 → 通用 → 键盘 → 键盘 → 添加新键盘，选择国际音标输入法。键盘输入不要求完全访问权限。更新检查在配套 App 打开或回到前台时进行，键盘扩展不联网检测。

## Android 10 及以上

下载 APK 并安装，支持 arm64-v8a 和 x86_64。打开 App，进入试打页启用键盘，再切换到国际音标输入法。当前为测试签名包，后续同签名版本可覆盖安装。实体手机兼容性尚未全面验证。

## 输入与设置

- 汉字模式输入拼音，候选汉字下方显示 IPA。点击汉字与 IPA 可以分别输入。桌面按数字选择汉字，Control＋回车输入 IPA。
- 词语优先匹配带调读音。仍有歧义时先手动选择读音，再确认 IPA。输入 `wu` 时，恶的读音限定在 wu，不混入 e。
- 桌面 Shift＋空格切换 IPA 模式。手机用中／IPA 按钮切换。输入 `a` 再选第一个候选输入 `a`。
- 数字 1–9 选择候选，每页可设 3–9 项。桌面按住 Shift 输入 2、1、4，手机依次上划数字 2、1、4，再点选 `˨˩˦`。0 保留原方案映射。
- 手机上点符号页可找到 `\`、`/` 等编码。反斜杠的第一个候选是 `˥`。长按字母键查看该键及首字母相同的组合输入。
- 设置页点击键盘编辑候选，IPA Plus 可点选替换或追加。支持导入和导出 CIN / JSON。

## 更新

0.1.1 起默认每天自动检查官网服务器与 GitHub。任一来源有更新的有效版本都会提示，两个来源均可用时取较新版本。一处连接失败时继续使用另一处，并稍后重试失败来源。设置页可手动检查或关闭自动检查。

检测只下载公开版本信息，不发送输入文本、词库或键位配置。升级由用户点击下载并安装，保留当前输入。版本信息与安装包 SHA-256 一起公开在仓库 `updates/latest.json`，包内保留各自的来源与许可。
