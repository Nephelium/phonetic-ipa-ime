# 四平台更新检测与官网分发

日期：2026-10-23。实施范围来自井井要求：Windows、macOS、iOS、Android 都检测 GitHub 与官网服务器的新版本，提醒升级，并在官网现有下载区新增可展开的四平台输入法下载入口。已获准上传本项目源码、安装包与官网改动。

## 设计

- 两个 HTTPS 清单独立读取：官网 `/releases/phonetic-ipa-ime/update.json`，GitHub 本仓 `updates/latest.json`。单个来源故障不阻断另一个来源，按当前平台的最高有效版本提示。
- 清单固定产品身份、格式版本、平台、版本号、发行页、服务器与 GitHub 下载链接、字节数与 SHA-256。只接受本官网和本 GitHub 仓库的 HTTPS 下载地址。
- 默认自动检测，两个来源均成功时采用 24 小时间隔，失败后最早 10 分钟重试，手动检查不受缓存限制。自动失败不弹窗打断输入，设置页可见结果和手动重试。
- 更新为提醒和打开下载入口，由用户安装。输入会话、映射和正在使用的系统输入源不自动替换。
- Windows 与 Mac 在自身进程启动及设置页触发检查，发现新版本提供不抢焦点的提醒。iOS 配套 App 启动/回到前台检查，键盘扩展不请求网络。Android 设置 App/输入法启动时只读取更新清单，网络逻辑不接收输入内容。
- 设置页有当前版本、检查更新、自动检查选项和可用版本下载入口。
- 对比其他路径：只读服务器会漏掉 GitHub 新版，只读 GitHub 在部分网络不可用。本次使用双来源。暂不实现静默安装和后台下载。

## 官网

在现有工具箱下载区下方增加折叠入口“下载国际音标输入法”。展开后四个平台均可下载，并显示各自必要安装条件。颜色、描边、阴影、圆角和排版沿用官网。使用原生 details/summary 保留键盘操作与无 JavaScript 展开。

官网有大量未发布的同期改动。部署以当前线上版本为基线，只应用本次下载区和相关元数据，不把其他未发布内容一起上传。维护原生成脚本，保留线上音频、工具箱下载、反馈和论文路由。
