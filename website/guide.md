# 国际音标输入法

输入拼音，选择带声调的国际音标；也可以按键位直接查找和点选 IPA、extIPA、VoQS 符号。支持 Windows、macOS、Android 和 iOS。

当前版本 **0.1.7 测试版**。[官网下载](https://www.phonetictoolbox.com/#ipa-ime-download) · [GitHub 下载](https://github.com/Nephelium/phonetic-ipa-ime/releases/tag/ipa-v0.1.7)。Mac 版双击安装，无需命令行工具。iOS 为待签名 IPA。

本项目基于 [水杉输入法 MSIME-Windows](https://github.com/metasequoiaime/MSIME-Windows) 开发。感谢水杉原作者及贡献者提供的输入法基础、原生界面与皮肤素材，保留上游历史、GPLv3 及原始署名。

## 第一次使用：拼音、汉字和音标怎样切换

先在系统中选择 **国际音标输入法**，再点进需要打字的文本框。新安装默认是 **输入拼音，输出音标**；以前保存的模式、规则和键位会保留。

**Windows / macOS 按下面三步切换：**

1. **默认：打拼音，输出音标。** 例如输入 `hao`，按数字选“好”，再按数字选读音，输入对应的 IPA。
2. **按 Caps Lock（大写锁定键）：打拼音，输出汉字。** 继续输入 `hao`，选择候选后输入“好”。再按 Caps Lock，恢复拼音输出音标。
3. **单按并松开 Shift：用字母或符号输入音标。** 进入 **IPA** 直接音标模式，字母和符号用于查找键位上的音标，例如按 `a`，再按 `1` 或空格确认首项。再次单按 Shift，返回拼音输入。

**Android / iOS：** 左下角按钮切换 **拼音／IPA**，显示的是当前模式。拼音模式下，上方 **音标／汉字** 按钮切换输出。还可以随时打开键盘上方的 **IPA Plus**，直接点选要输入的音标。电脑设置中的 IPA Plus 用于查看音标和编辑键位。

**注意：单按 Shift 切换模式；按住 Shift＋1–5 输入声调。** 这两种操作不同。Mac 也支持 Shift＋空格切换输入方式，并可点击音标／汉字按钮切换输出。

| 平台 | 拼音查字，默认输出 IPA | 拼音查字，默认输出汉字 | 直接音标键盘 |
|---|---|---|---|
| Windows 悬浮工具栏 | **IPA** | **汉字** | **IPA** |
| macOS 候选栏空闲状态 | **拼音 → 音标** | **拼音 → 汉字** | **IPA · 点选音标** |
| Android / iOS | 左下角 **拼音**，上方 **音标** | 左下角 **拼音**，上方 **汉字** | 左下角 **IPA** |

直接音标模式统一显示为 IPA。手机左下角显示的是当前模式，点一下会切换到另一种。上方正在显示的拼音、编码或 `tone:214` 是待确认的组合，选定候选后才会输入正文。

## 跟着输入第一个音标

本文的音标例子使用 **Standard Chinese Beijing 宽**。如果当前选择其他规则，音标写法会随之变化。

**先试一个带多音字的词：快乐。** 乐有 lè、yuè 等读音，在快乐里读 **lè**。输入完整词语时，输入法会结合词语读音进行转写。

**电脑：输入快乐的音标**

1. **点进文本框。** Windows 用 Win＋空格选择国际音标输入法；Mac 从菜单栏的输入法菜单选择。先在空白文本框中练习，光标应停在准备输入的位置。
2. **进入拼音输入，输出选音标。** Mac 空闲候选栏显示拼音 → 音标。Windows 拼音输出音标时，工具栏显示 IPA；如果先前进入过直接音标模式，单按并松开 Shift 返回拼音；显示汉字时，按一次 Caps Lock 切回音标输出。
3. **依次按 k、u、a、i、l、e。** 输入 `kuaile`。候选窗会显示正在组合的拼音，有时按音节显示为 `kuai’le`。此时还在选词，文字尚未最终输入正文。
4. **找到候选快乐。** 每项上行显示汉字，下行显示对应音标。先看快乐前面的编号。假如本页快乐排在第 1 项，就按 `1`；排在其他位置，就按它自己的编号。也可以直接点击快乐下方的音标。
5. **确认词语读音。** 快乐的词语读音为 `kuai4 le4`，通常选中词语即可输入整词音标。如果出现读音页，再按所需读音前面的数字，或点击这一项。候选和读音页的编号分别计算。
6. **查看正文结果。** 使用本页默认规则时，得到 **kʰuai˥˩ lɤ˥˩**。这一步已经包含声调，无需再给这两个音节重复补一次声调。

**手机：输入同一个词**

1. 点进文本框，并把系统键盘切换为国际音标输入法。左下角应显示 **拼音**，上方输出按钮应显示 **音标**。显示 IPA 时，点左下角切回拼音；上方显示汉字时，点它切回音标。
2. 依次点 `k、u、a、i、l、e`。观察键盘上方的拼音和候选，找到快乐。
3. **点快乐下方的音标**，明确选择音标输出；也可以轻点候选前的编号所对应的数字键。若本页排第 1，就轻点 `1`。这里是轻点，不上划数字键。
4. 若出现读音列表，再点 `kuai4 le4` 对应的读音，或点它前面编号对应的数字键。确认后，正文出现 **kʰuai˥˩ lɤ˥˩**。

**对照同音字母：选择快了**

1. 同样输入 `kuaile`，这次选择候选快了。图中排第 2 项，电脑可按 `2`，手机可点快了下方的选择读音。
2. 随后实际待选的是快的 `kuai4／kuai5`。选择 `kuai4`，图中排第 1 项，按 `1` 或点这一项。
3. 了按输入的 `le` 匹配为轻声，整词得到 **kʰuai˥˩ lɤ**。快乐的乐读 lè，结果为 **kʰuai˥˩ lɤ˥˩**，两者最后一音节的声调不同。

**再试多音字：按两次数字选择好的读音**

1. 保持拼音输入、输出音标，输入 `hao`。先看候选中好前面的数字。
2. 假如好排第 1 项，**先按 `1` 选好**。此时是在选汉字，尚未决定读哪一个音。
3. 读音页会列出 `hao3`、`hao4` 等读音。**重新看这一页的编号**：假如 `hao4` 排第 2 项，再按 `2`，输入 **xau˥˩**。假如选择 `hao3`，则输入 **xau˨˩˦**。实际编号以当前页为准。
4. 手机同样可以先选好，再点读音或轻点读音编号。电脑可用 Ctrl＋Shift＋Enter 返回选字，Mac 对应 Control＋Shift＋回车。手机可按退格返回待选内容。

**记住选择顺序：先选字，再选读音。** 只有仍有多个读音需要确认时，才出现第二次选择。词语已经确定读音时，可以直接输出。单独输入 `le` 查乐，会保留与 le 对应的读音；输入 `yue` 查乐，则使用与 yue 对应的读音。

**手机输入较长内容：** 可以一次输入完整词语的拼音，例如 `quanguorenmindaibiaodahui` 查全国人民代表大会。手机端目前按固定词库查词，未收录的整句拼音可能没有候选。输入长句时，先分成词语，逐词确认后继续输入。

**怎样确认自己还在拼音模式？** 拼音候选上行是汉字，下行是音标。Windows 的拼音音标输出和直接音标模式都显示 IPA，需要结合候选内容区分。单按 Shift 切换后，输入字母即可看到两类候选的区别。

**选错或暂时不想输入？** Windows / Mac 按 Esc 取消当前组合。上下键移动高亮项，Page Up / Page Down 翻页。空格确认首项或当前高亮项，确认后再按一次空格才会在正文中插入空格。

**上图展示候选窗布局。** 实际候选的汉字、顺序和编号随输入内容变化，请对照自己当前页面上的编号操作。

**想输出汉字快乐，怎样切换？**

1. 先确认或取消当前候选。电脑在拼音模式按一次 **Caps Lock（大写锁定键）**；手机点上方的 **音标** 按钮，使它显示 **汉字**。
2. 再输入 `kuaile`。输入方式仍是拼音。找到快乐后，按其编号，或直接点击上行汉字快乐。
3. 正文得到 **快乐**，不再是音标。Windows 工具栏显示汉字，Mac 显示拼音 → 汉字，手机上方输出按钮显示汉字。
4. 想恢复拼音输出音标，电脑再按一次 Caps Lock，手机把汉字按钮切回音标。

## 直接输入单个音标

这一模式适合输入单个音标。字母或符号用于查找键位上的音标，不用先输入汉字拼音。

**Windows / macOS：按 a，再确认音标**

1. 先确认已有候选，或按 Esc 取消当前组合。
2. **单独轻按 Shift，然后松开。** 不同时按其他键。进入 IPA 直接音标模式，Mac 显示 IPA · 点选音标，Windows 工具栏显示 IPA。Mac 也支持 Shift＋空格切换。
3. 按 `a`。候选区应显示 a 键位的音标列表，正在组合的编码是 `a`。
4. 按 `1`，或按空格确认首项，正文得到 **a**。如果想选其他音标，按它前面的编号。
5. 再按其他字母或符号，就能继续查找相应键位的音标。候选多时，可翻页后按当前页编号选择。
6. 想回到拼音查字，**再次单按并松开 Shift**。这时输入 `hao` 会出现汉字候选及其下方音标。

**Android / iOS：短按字母键，点选音标**

1. 确认已有的拼音候选，再点左下角模式按钮，直到显示 **IPA**。
2. 找到带 **···** 的按键，例如 g。省略号表示它有多个音标或组合输入。
3. **短按 g 一次，再松手。** 屏幕弹出这一键的音标选择面板，打开面板本身不会输入 g。
4. 在面板中找到 **ɠ**，点它一次，正文就输入 **ɠ**。候选较多时，可先上下滑动面板再点选。
5. 没有 ··· 的单项键会直接输入，无需再选。关闭选择面板不会输入任何符号。
6. 想回到拼音查字，点左下角，直到重新显示 **拼音**。

<p><img src="docs/images/0.1.6/android-picker.png" width="260" alt="Android：短按字母后打开音标选择面板"> <img src="docs/images/0.1.6/ios-picker.png" width="260" alt="iOS：点选面板中的音标输入"></p>

**斜杠、反斜杠和更多键位**

电脑在直接音标模式按 `/`、`\` 等符号键，再选候选。手机先点 **符号** 打开符号页，再点相应按键。`\` 收录声调符号，首项是 ˥，`/` 默认输出斜杠。键位和候选可在设置的音标键盘中查看或修改。

IPA 模式的 `0` 保留原码表映射，其他普通数字在没有候选时输入数字。电脑输入含数字的连续编码时，可以使用 `code:` 前缀。

## 加声调：按住 Shift，或上划数字

先确认当前音标或汉字，再开始声调输入。五度调值中 **1 最低、5 最高**。下面输入一个 **214** 调值，最终可以选择五度调符号、上标数字或普通数字。

**Windows / macOS：按住 Shift，依次按 2、1、4**

1. 确认正文中的音标已上屏，候选区没有等待选择的拼音或音标编码。
2. **按住 Shift，不松开。** 用另一只手依次按数字 `2`、`1`、`4`，按完后再松开 Shift。
3. 候选区显示 `tone:214`。这表示调值正在组合，声调尚未最终输入正文。
4. 选择需要的写法：首项 **˨˩˦** 是五度调符号，后面还有 **²¹⁴** 和 **214**。按候选前面的数字，或按空格确认首项。
5. 选择首项后，正文得到 **˨˩˦**。如果还要插入一个空格，确认后再按一次空格。

**单按 Shift 用于切换拼音／IPA，按住 Shift＋数字用于输入调值。** 输入声调时，要从第一个数字到最后一个数字一直按住 Shift。

**Android / iOS：在数字 2、1、4 上分别向上划**

1. 先确认当前候选，找到键盘最上排数字键。
2. 手指按在 `2` 上，向上划动后松手；再分别在 `1`、`4` 上做同样的上划动作。
3. 候选区出现 `tone:214`，并列出 **˨˩˦ / ²¹⁴ / 214**。
4. **直接点需要的候选**，或按空格确认首项，声调就会输入正文。
5. 进入声调组合后，轻点数字 `1–5` 会继续追加调值。要确认结果时，请点候选或空格。

## 随时查完整音标表，切换转写规则

**手机：打开 IPA Plus，直接点选输入**

1. 先把正在组合的拼音或声调确认完成，再点键盘上方的 **IPA Plus**。
2. 音标表打开后，顶部可切换 **IPA / extIPA / VoQS** 分类。
3. 在搜索框输入音标或中文名称，或直接滑动查找。辅音矩阵可左右滑动，整页可上下滑动。
4. 点想输入的符号，符号就会加入正文。音标表可以连续点选，不必每输入一个符号就关闭。
5. 默认字号为 50%，最低可调至 20%，可用 **字号 − / 字号 ＋** 调整。附加符号旁的辅助圆圈用于辨认，实际输入不带辅助圆圈。
6. 完成后点 **返回键盘**，继续使用拼音或直接音标按键。

**电脑设置中的 IPA Plus 用于编辑键位。** Windows 默认适合页面宽度，最高 70%，最低可调至 20%；放大后可用左右移动按钮或 Shift＋滚轮查看表格。 打开设置的音标键盘页，点要修改的键，再选中一个候选，用 IPA Plus 点选替换或追加符号，最后保存方案。手机键盘内的 IPA Plus 可以直接向正在编辑的正文输入。

**切换转写规则：先选规则，再输入拼音**

1. 先确认当前候选，找到规则按钮。Windows 点悬浮工具栏中的规则名称，菜单向上展开；Mac 点候选栏的规则菜单；手机点键盘上方 **规则**。
2. 点选所需规则，例如 **Standard Chinese Beijing 宽**。菜单关闭后，规则名称或已选标记会对应刚选中的方案。
3. 回到文本框，重新输入 `kuaile`，再选快乐，查看这一规则下的音标。切换规则不会改写正文中已经输入的音标。
4. 想对比另一套方案，再打开规则菜单选择它，然后重新输入同一个词。

共十套规则：

- Standard Chinese Beijing 宽 / Standard Chinese Beijing 严
- 胡裕树《现代汉语》、黄伯荣／廖序东《现代汉语》、钱乃荣《现代汉语》
- 吴宗济、赵元任《汉语口语语法》、《汉语方音字汇》
- UntPhesoca 宽 / UntPhesoca 严

直接音标键盘使用自己的键位方案，切换拼音转写规则不会替换它。各套规则的来源见 [Rules-SOURCES.json](prototype/resources/ipa/Rules-SOURCES.json) 与 [来源与许可](prototype/THIRD_PARTY.md)。

## 常见问题与设置

**Shift＋1–5 仍输入 !@#，或 Caps Lock 没反应？** 先确认系统当前选择的是国际音标输入法，并查看上表中的状态。Windows 升级后，保存草稿，完全退出并重新打开仍在运行的应用，使它重新加载新版输入法 DLL。只关窗口可能仍留在后台，无需重启电脑。

**输入字母没有预期音标？** 想拼音查字时回到拼音模式，想选单个音标时进入直接音标模式。手机左下角显示 IPA 时短按带 ··· 的键；电脑显示 IPA 时先按 a，再按 1 试输首项。候选尚未确认时不会进入正文。

**退格与键位编辑**：Android 按住退格连续删除，松手或移出按键后停止。设置中点按键位，按从左到右的顺序编辑候选后保存，支持导入／导出 IPA 码表（.cin）与 JSON、每页 3–9 项。附加符号显示辅助圆圈和 Unicode 码位，实际输入不包含辅助圆圈。

**皮肤与图标**：Windows 新安装默认普通蓝色大肥鱼，保留探头、国庆献礼等其他选择。四端图标为大肥鱼抱 ə。Windows 关于页可选本机 PNG / JPEG / BMP 图片作为设置窗口、任务栏和应用内显示图标，最大 10 MB，可恢复默认；程序文件图标保留默认。图片仅保存在本机。

**更新**：设置中可手动检查或关闭自动检查。官网与 GitHub 任一版本源有新版时提示下载，由用户安装。iOS 在配套 App 前台检查。请求不包含按键、宿主文本、词库或个人方案。
