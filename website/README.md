# 官网输入法下载组件

`ime-downloads.html` 、`ime-downloads.css` 与 `ime-downloads.js` 为官网首页四平台下载区的维护副本，使用原生 details/summary，默认收起。鼠标悬停预览，移开收起，点击固定展开，再点按钮、空白处或 Esc 关闭。手机点击展开。面板悬浮显示，不撑高首屏，没有 JavaScript 时仍可点击展开。正式页面维护源仍在 PhoneticToolbox 的 `scripts/build_website_expansion.py`。

2026-10-23 发布基于线上首页，仅加入此组件与独立样式引用。未发布 PhoneticToolbox 本地的其他页面改动。升级版本时先上传并核验四个包，再更新链接和版本清单。
