# Android 输入法

- `app/src/main/java/`：系统输入法、候选会话、键位设置和资源索引。
- `app/src/main/cpp/`：JNI 桥接，复用主仓库 `engine/ipa/`，不重写音标和多音字规则。
- `scripts/`：项目内构建、独立模拟器和验证入口。
- 使用 Apple 资源准备脚本生成的同一套固定资料，禁止读取个人学习词库。
- 不申请网络权限。导入导出使用系统文档选择器。
- 模拟器测试只操作本项目新建的设备和明确的 serial，不操作其他正在运行的设备。
- APK、SDK/NDK、模拟器数据和生成资料不提交；源码、许可和复现命令需要保留。
